Journal App Backend

A simple backend application for a Journal App built using Spring Boot and MongoDB. This project provides REST APIs for managing journal entries, allowing users to create, read, update, and delete (CRUD) journal records.

Features
Create a new journal entry
View all journal entries
View a specific journal entry by ID
Update an existing journal entry
Delete a journal entry
MongoDB integration using Spring Data MongoDB
RESTful API architecture
Tech Stack
Java 17+
Spring Boot
Spring Data MongoDB
MongoDB
Maven
